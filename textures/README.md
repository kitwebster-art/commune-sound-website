# Commune Sound texture studies

Five isolated full-page background studies for comparing material direction
without changing `/portal/` or the live homepage.

## Visual contract

- Subject: a continuous textured atmosphere behind the existing Commune Sound
  page, logo and venue image.
- Identity: black, hot pink, violet, cyan and pearl; tactile rather than flat;
  musical and nocturnal rather than corporate or wellness-coded.
- Motion: slow field drift with restrained pointer parallax and no interaction
  that blocks scrolling.
- Invariants: no dominant central black hole, no closed pill-shaped composition,
  legible wordmark and event copy, corrected cool venue photograph, continuous
  texture through every section, zero horizontal overflow at 390 pixels.
- Allowed divergence: each option changes the field structure, surface scale and
  highlight behaviour while retaining the same page content and image grade.
- Frame budget: 17 ms desktop, 24 ms mobile. The fragment field renders at 0.70
  desktop scale and 0.66 mobile scale.

## Field bundle

```text
screen coordinate + pointer + scroll
  -> one shared low-frequency domain warp
  -> option-specific material field
  -> detail and highlight causes
  -> shared cool palette and distributed black-pocket mask
```

## Options

1. `velvet-interference`: broad folds plus crossed high-frequency weave.
2. `liquid-chrome`: warped marble phase plus a shared specular edge.
3. `holographic-grain`: broad chromatic clouds plus display-domain film grain.
4. `topographic-silk`: shared height field consumed by folds and contour lines.
5. `cosmic-lacquer`: animated cellular distance consumed by dark cores and
   pearlescent rims.

All options expose deterministic `time` and `seed` query parameters plus
`debug=field` and `debug=no-post` inspection modes.
